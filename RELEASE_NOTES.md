# MiMiNavigator v0.9.9.6.7

A reliability release for network storage, permission restarts, and application lifecycle.

## Highlights

- Network Neighborhood now merges the same device discovered through saved connections, Bonjour, FritzBox, SSDP, or Fing into one host.
- SMB shares use the same application-managed mount path across Network Neighborhood and Connect to Server.
- MiMiNavigator now enforces a single running instance, including during permission-triggered restarts.

## Changed

- SMB mount paths are generated by shared `NetworkKit` logic under Application Support.
- Existing matching SMB mounts are detected and reused instead of creating parallel sessions.
- Application-managed and system SMB mounts are both recognized when restoring saved connections.
- Restart requests close Settings immediately and wait for the old process to exit completely before launching the replacement.
- A second launch activates the existing MiMiNavigator instance and terminates without initializing another application session.

## Fixed

- The same network host no longer appears twice when one source reports a hostname and another reports its IP address.
- Network disks no longer fail because the sandboxed app attempted to create `/Volumes/<share>`.
- Mount failures now display their real cause instead of always suggesting an authentication problem.
- AFP URLs are no longer passed incorrectly to `mount_smbfs`.
- SMB credentials are no longer included in mount logs.
- Restart Now no longer uses `open -n`, which explicitly created a second MiMiNavigator process.
- The Settings window no longer remains visible while the old process waits for termination cleanup.
- Repeated Restart Now clicks cannot schedule multiple relaunch helpers.

## Internal

- Added typed SMB mount errors and tests for managed mount-path generation.
- Preserved compatibility for deprecated public `NetworkKit` mount APIs.
- Replaced deprecated address decoding in Bonjour discovery.
- Extracted permission restart UI and folder presentation state from the oversized Settings pane.

## Validation

- `NetworkKit` tests pass.
- Debug builds complete successfully.
- The release pipeline performs a clean signed build, DMG verification, notarization, stapling, and Gatekeeper assessment.

## Download

The DMG is signed, notarized by Apple, and includes an Applications shortcut for drag-to-install.
