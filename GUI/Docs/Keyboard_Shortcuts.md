# Keyboard shortcuts

MiMiNavigator provides selectable shortcut profiles in **Settings → Hotkeys**. Existing custom bindings are preserved when the application is updated.

## Total Commander

The Total Commander/Norton Commander layout is the default. Function keys are displayed as `F2`, `F4`, and so on, regardless of whether the physical keyboard requires holding `Fn`.

Combinations reserved globally by macOS remain unassigned. If a user records one of those combinations, MiMiNavigator shows a warning and cancels the assignment. `F5` therefore has no default action; users can choose another Copy shortcut after changing the corresponding macOS setting.

Choose a profile from the preset menu at the bottom of **Settings → Hotkeys**. Any individual shortcut can then be recorded directly; changing one assignment turns the active profile into **Custom**.

## Workspace

| Shortcut | Action |
|----------|--------|
| `⇧⌘P` | Show or hide the persistent Preview pane |

The Preview command is also available from the application toolbar and the Show and View menus.
