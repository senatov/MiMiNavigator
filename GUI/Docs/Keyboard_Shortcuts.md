# Keyboard shortcuts

MiMiNavigator provides selectable shortcut profiles in **Settings → Hotkeys**. Existing custom bindings are preserved when the application is updated.

## macOS Safe (recommended)

This is the default profile for new installations. It avoids relying on bare F1–F12 keys because Apple keyboards normally use them for brightness, Mission Control, Spotlight, media playback, volume and other system features.

| Action | Shortcut |
| --- | --- |
| Rename | `⌥R` |
| Temporary backup | `⌥B` |
| Edit | `⌥E` |
| Copy | `⌥C` |
| Move | `⌥M` |
| New folder | `⌘⇧N` |
| Move to Trash | `⌘⌫` |
| Find files | `⌘F` |

## Total Commander

The traditional F2–F8 command layout remains available as an optional profile. On an Apple keyboard it may require holding `Fn`, or enabling **Use F1, F2, etc. keys as standard function keys** in macOS Keyboard settings. Hardware assignments and available options vary by keyboard and macOS version.

Choose a profile from the preset menu at the bottom of **Settings → Hotkeys**. Any individual shortcut can then be recorded directly; changing one assignment turns the active profile into **Custom**.
